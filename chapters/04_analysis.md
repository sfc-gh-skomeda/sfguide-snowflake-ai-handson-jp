# 第4章 SQL でアドホック分析（目安 40 分）
## この章でやること
ストーリー「新商品の販促効果を振り返る」に沿って、集計・JOIN・CASE・ウィンドウ関数・JSON（VARIANT）の扱いを体験し、結果をグラフにします。
- 新商品: 商品ID 11（2026年4月発売）
- キャンペーン: 2026年5月の1か月間
## 前提
第0章・第3章が終わっていること。
## 手順
新しいワークシートに [sql/04_analysis.sql](../sql/04_analysis.sql) を貼り付け、最初の USE 3文を実行してから、課題ごとに1文ずつ実行します。
### 課題1 カテゴリ別の売上（棒グラフ）
結果の上の「Chart」を押し、棒グラフにします。
### 課題2 新商品の月別販売数（折れ線グラフ）
「Chart」で折れ線グラフにし、5月だけ大きく伸びていることを確認します。
### 課題3 キャンペーン前・中・後の比較（CASE）
### 課題4 前月差と累計（ウィンドウ関数 LAG / SUM OVER）
### 課題5 アプリ利用ログ（JSON）を表にする
中身を見る → `:` で取り出す → `::` で型をそろえる → `LATERAL FLATTEN` で配列を展開 → ビューにする、の順に進みます。

## うまくいかない時
- 日本語の列名でエラー: `AS "件数"` のようにダブルクォートで囲みます。
- グラフが思った形にならない: 右側の設定で X 軸に「月」、Y 軸に「販売数」を選びます。
- 時間が足りない: 課題4・5は実行して結果を見るだけで構いません。
