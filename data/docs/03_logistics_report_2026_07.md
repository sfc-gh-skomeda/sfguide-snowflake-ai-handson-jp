# 2026年7月 西日本物流センター 出荷遅延についての報告

> 架空の食品メーカーの社内文書です（ハンズオン用の合成データ）。

- 報告者: 物流部 西日本物流センター / 報告日: 2026年8月5日
- 配布先: 営業本部、マーケティング部、お客様相談窓口

## 1. 概要
2026年7月3日から7月29日まで、西日本物流センターの自動倉庫の設備故障により、**近畿エリア向けの出荷が通常の約3割**に落ちました。
特に、5月のキャンペーン後も注文が多かった **さくさくナッツバー 抹茶（商品番号 11）** で、近畿の店頭での品切れが続きました。

## 2. 影響
| 項目 | 内容 |
|---|---|
| 期間 | 2026年7月3日〜7月29日 |
| 地域 | 近畿（大阪・京都・兵庫・奈良・滋賀・和歌山） |
| 主な商品 | さくさくナッツバー 抹茶（ほかの商品は在庫で対応でき、影響は小さい） |
| 販売への影響 | 近畿の抹茶ナッツバーの7月の販売数は、6月の約3割 |
| お客様の声 | 「大阪の店で見つからない」「販売終了したのか」などの問い合わせが7月に集中 |

## 3. 原因
- 自動倉庫の搬送装置の部品が故障し、交換部品の取り寄せに約3週間かかった
- 予備の手作業での出荷は、注文の多い商品から順番に行ったが、新商品の出荷量の見込みが低く設定されていた

## 4. 対応
- 7月29日に設備が復旧。8月第1週で近畿の店頭在庫は通常に戻った
- 交換部品を常に在庫として持つ（2026年9月から）
- 新商品の出荷量の見込みを、キャンペーン後の実績で見直す仕組みを営業本部と作る
- お客様相談窓口のマニュアルに「店頭で見つからない」の回答例を追加（第3版）

## 5. 今後のお願い
営業本部・マーケティング部は、7月の近畿の数字を見るときに、この出荷遅延の影響を考えてください。
