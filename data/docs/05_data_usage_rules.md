# 社内のデータ利用ルール（データ分析基盤）

> 架空の食品メーカーの社内文書です（ハンズオン用の合成データ）。

- 管理: 情報システム部 / 施行: 2027年1月1日

## 1. 目的
販売・在庫・お客様の声などのデータを、部門をこえて安全に使えるようにします。

## 2. 使えるデータと申請
| データ | 置き場所 | 申請 |
|---|---|---|
| 販売（日別・店舗別） | 分析基盤のマート | 部門長の承認で利用可 |
| 商品マスタ・キャンペーン | 分析基盤のマート | 申請不要（全社員が閲覧可） |
| お客様の声（問い合わせ文） | 分析基盤の VOC 領域 | お客様相談窓口の承認が必要。個人を特定できる情報は削除済み |
| 社内文書（マニュアル・報告書） | 文書検索 | 申請不要。部外秘の文書は所属部門のみ |

## 3. 利用を始める手順（1月から）
1. 社内ポータルの「データ分析基盤 利用申請」から、使いたいデータと目的を書いて申請する
2. 承認されると、所属部門のロール（権限のまとまり）が付与される
3. 分析用のウェアハウス（計算資源）は部門ごとに用意する。サイズは原則 X-Small から始め、遅い場合はまず SQL を見直す
4. 使い終わったウェアハウスは自動で止まる設定（60秒）にしておく

## 4. 守ること
- データを社外のサービスにアップロードしない
- 結果を CSV で持ち出すときは、個人が特定できる情報が含まれていないか確認する
- AI 機能（文章の要約・分類、質問への回答など）は、情報システム部が用意した環境でのみ使う
- 困ったときは、情報システム部の問い合わせ窓口へ
